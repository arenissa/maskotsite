# 3D-маскот: модель, референс, замена

## Где лежит модель

`assets/mascot-procedural.glb` — бинарный glTF 2.0. Он создаётся из `js/geometry.js` командой:

```bash
npm run export:model
```

Модель содержит 32 отдельных настоящих 3D-меш-объекта: скруглённый объёмный красный куб, углубления глаз, белые глаза, зрачки, световые блики, брови, улыбку, обе руки, перчатки и кулаки, ноги и крупные ступни. Размер файла около 0.75 МБ. Элементы можно открыть/изменить в Blender; используется базовый glTF-PBR материал.

В отличие от 2D-«псевдокуба», геометрия имеет настоящие переднюю, заднюю, боковые и верхние поверхности, в том числе тыльную часть рук и ног. Это позволяет увидеть тыл модели при 360° вращении.

## Как заменить на другой GLB

1. Поместите ваш новый файл, например `assets/mascot-final.glb`, в `assets/`.
2. Укажите `MASCOT_GLB_PATH: 'assets/mascot-final.glb'` в `js/config.js`.
3. Обновите страницу. Если новый GLB не может быть прочитан, автоматически сохраняется процедурная модель, а в консоли выводится предупреждение.
4. Для удобного масштаба сохраните габариты примерно **4.6 × 3.8 × 2.1 условных единиц** с центром куба тела около `(0,0,0)`; перед персонажа направлен в **+Z**, вертикаль — **+Y**. Иначе потребуется подправить `baseScale`, положение камеры или offset в `js/mascot3d.js`.

Встроенный облегчённый GLB-загрузчик поддерживает: GLB 2.0 с BIN-чанком; нескиненные mesh primitives в режиме TRIANGLES; positions и normals; индексные сетки до 65 535 вершин на primitive; переводы, повороты, масштаб узлов; PBR `baseColorFactor`. UV-текстуры, morph targets, скелеты и skeletal animation в этом импортёре **пока не поддерживаются**. Если финальная брендовая 3D-модель использует сложные текстуры/риг, рекомендуется подключить полнофункциональный Three.js GLTFLoader или React Three Fiber. Это не помешает сохранению остальной структуры сайта.

Для дополнительной анимации частей персонажа используйте `node.extras.group` в glTF с метками `body`, `face`, `eyes`, `left`, `right`, `legs`. Наш экспорт задаёт их автоматически. Для внешнего GLB без таких групп весь персонаж всё равно вращается, но целевые движения глаз/правой руки потребуют отдельной разметки рига.

## Как устроено вращение

`scroll.js` рассчитывает нормализованное положение на sticky-секции. Для движения от 0.264 до 0.618 прогресса `mascot3d.js` задаёт `rotationY = 2π × smoothstep(...)`. Тем самым прокрутка назад обращает анимацию; при остановке не происходит самостоятельных бесконечных оборотов. При включённом reduced motion принудительное вращение выключено.

## Что важно для окончательного релиза

Сейчас это **авторская процедурная интерпретация** по предоставленной фотографии, а не идентичная лицензированная исходная скульптура. Для абсолютно точных форм перчаток, пропорций, положения бровей и настоящего лицевого рига нужна утверждённая production GLB/BLEND-модель или индивидуальная ручная работа 3D-художника с согласованием.
