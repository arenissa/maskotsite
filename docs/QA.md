# Чек-лист браузерной приёмки

После запуска `npm run dev` проверьте в Chrome, Firefox и Safari (реальные устройства или DevTools):

- [ ] Страница открывается без console errors и без горизонтальной прокрутки на 320, 390, 768, 1024 и 1440 px.
- [ ] Первый экран содержит оригинальный логотип RED SQUARE и подпись для прокрутки.
- [ ] При прокрутке вниз логотип исчезает, красный 3D-куб раскрывается, появляются лицо и конечности.
- [ ] При следующем скролле маскот показывает переднюю, боковую и заднюю грани; прокрутка назад возвращает прежний угол без скачка.
- [ ] Вращение маскота НЕ продолжается само по себе при неподвижной странице (разрешены лёгкие моргания/жесты).
- [ ] Окно истории показывает точный текст «Привет! Я твой квадратный помощник и у меня такая история» и placeholder без вымышленной биографии.
- [ ] История исчезает до показа второго окна; два попапа одновременно не перекрывают друг друга.
- [ ] Окно чата показывает «Привет! Го пообщаемся»; без URL кнопка недоступна, после установки настоящего URL переходит на него.
- [ ] В секции мерча ровно пять карточек: кружки, фигурки, ручки, футболки, брелки; все изображения отсутствуют, цен нет.
- [ ] Карусель реагирует на drag зажатой мышью, горизонтальный трекпад, свайп и кнопки-стрелки.
- [ ] Обычное вертикальное колёсико над каруселью прокручивает СТРАНИЦУ, а не блокирует её.
- [ ] На сфокусированной карусели работают клавиши ArrowLeft/ArrowRight/Home/End.
- [ ] При `prefers-reduced-motion: reduce` все окна остаются доступны и чтение контента не зависит от 3D-анимации.
- [ ] При запрещённом WebGL видна статичная фотография персонажа вместо чёрного/пустого блока.
- [ ] Lighthouse: отладить обнаруженные проблемы accessibility/performance; отдельно измерить FPS на целевых мобильных устройствах.

Сделанные автоматические проверки: `npm test`, `npm run build`, `npm run export:model`, валидация GLB внешней библиотекой trimesh, успешная отдача HTML встроенным Node-сервером. В среде подготовки автоматическая навигация Chromium была отклонена системной политикой `ERR_BLOCKED_BY_ADMINISTRATOR`, поэтому фактические браузерные пункты выше должны быть выполнены отдельно перед промышленной публикацией.
