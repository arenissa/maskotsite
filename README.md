# RED SQUARE — интерактивный промосайт маскота

**Готовый одностраничный frontend-проект** на русском языке: логотип → превращение в объёмного персонажа → полный оборот 360° по прокрутке → история → приглашение в чат → горизонтальная карусель пяти категорий мерча.

В составе — **исходники, полноценная 3D-геометрия, GLB-файл, оптимизированная фотография для fallback, production-сборка `dist/`, конфигурация, автотесты и инструкция**.

## 1. Как запустить

Требуется **Node.js 18+**. Никакие npm-пакеты устанавливать НЕ требуется; интернет для самого сайта не нужен.

```bash
# Распаковать архив, открыть терминал в этой папке:
npm run dev
```

Откройте браузер: **http://localhost:3000**.

При необходимости другой порт:

```bash
node scripts/server.mjs --port=8080
```

Проверить исходники и собрать версию для публикации:

```bash
npm test
npm run build
npm run preview
```

После `npm run build` готовый статический сайт окажется в папке **`dist/`**. Команда `npm run preview` открывает эту сборку на http://localhost:3000. Также можно разместить содержимое `dist/` на любом обычном статическом хостинге.

> **Не рекомендуется открывать `index.html` напрямую двойным щелчком (`file://`)**: современные браузеры иногда блокируют ES-модули при загрузке с диска. Откройте сайт через локальный сервер, как показано выше.

## 3. Как изменить контент (главное)

Откройте **`js/config.js`**. Там находятся все редактируемые материалы:

```js
export const CONFIG = {
  CHATBOT_URL: '', // https://example.com/your-real-bot
  MASCOT_GLB_PATH: 'assets/mascot-procedural.glb',
  STORY_HEADING: 'Привет! Я твой квадратный помощник и у меня такая история',
  STORY_TEXT: '',  // вставить утверждённую биографию
  CHAT_HEADING: 'Привет! Го пообщаемся',
  MERCH: [
    { id: 'cups', title: 'кружки', image: '' },
    // ... пять карточек
  ]
};
```

**История.** Вместо пустой строки `STORY_TEXT` вставьте утверждённый текст. Он автоматически заменит временный placeholder. До получения истории вымышленная биография не публикуется.

**Чат.** Заполните `CHATBOT_URL` действительным `https://` адресом. Кнопка «Перейти к общению» станет активной, ссылка откроется в отдельной вкладке. Никакая фальшивая переписка в демо не показывается. Для встроенного API/iframe см. [docs/CHATBOT.md](docs/CHATBOT.md).

**Мерч.** Для каждой карточки укажите `image: 'assets/merch/cups.webp'` или другую фотографию. Поддерживаются PNG, JPG, WebP, AVIF (при поддержке браузером). Добавьте файлы в `assets/merch/`. Можно указать и `https://...` адрес. Пока фотографии не добавлены, остаются нейтральные пустые слоты. Карточки идут в заданном порядке: кружки, фигурки, ручки, футболки, брелки. Цены, скидки и ссылки на вымышленные товары не добавлялись.

**Логотип.** Замените `assets/red-square-logo.png` своим утверждённым оригиналом и при необходимости обновите ссылку на файл в `index.html`. Исходный пользовательский PNG без обрезки: `assets/red-square-logo-original.png`. Для окончательного выпуска рекомендуется фирменный векторный файл SVG без растра: предоставленное исходное изображение небольшого размера.

**3D-модель.** Файл `assets/mascot-procedural.glb` — настоящий экспортированный GLB с отдельными элементами персонажа. Открывается в Blender и других GLB-редакторах. Можно заменить его, сохранив путь, или обновить `MASCOT_GLB_PATH` на новый. Подробнее об ограничениях импортера и названиях групп: [docs/MODEL.md](docs/MODEL.md).

> После редактирования `config.js` для локального сервера достаточно обновить вкладку. Для сайта в сети повторите `npm run build` и опубликуйте новую папку `dist/`.

## 5. Архитектура и мотивировка стека

ТЗ допускало альтернативу рекомендованному Next.js / React / Three.js, если она не ухудшает интерактивность. Использована небольшая **автономная frontend-архитектура на нативном ES Modules + WebGL 1.0**, с собственным программным 3D-шейдером и генератором геометрии. Плюсы: проект **действительно запускается без `npm install`**, работает даже без CDN, не требует будущего API для демо, быстро деплоится как статический сайт.

**Важно:** здесь нет Next.js, React Three Fiber, GSAP, физически корректной PBR-визуализации или действующего серверного API. GLB-файл содержит PBR-параметры материала, но рендер в браузере использует лёгкий собственный шейдер со студийным освещением. Это осознанное техническое отличие от рекомендованного стека; финальная production-версия с более сложной анимацией лица/скелета может быть перенесена на Three.js/React при необходимости.

Анимация вращения в `js/mascot3d.js` вычисляется из реального прогресса скролла в `js/scroll.js`. Это не autoplay-анимация: прокрутка вверх возвращает предыдущий угол, а на остановке страницы полный оборот не продолжается. Небольшие самостоятельные моргания/жесты — вторичная «жизнь» маскота.

## 6. Публикация

**Vercel:** импортируйте папку проекта через Git; `vercel.json` задаёт `npm run build` и `outputDirectory=dist`. Выберите Framework Preset: **Other** (это статический проект, не Next.js). Можно загрузить содержимое `dist/` и на Netlify, обычный nginx, GitHub Pages (для Pages со вложенным путём потребуется поправить абсолютные якоря только при необходимости).

**Собственный сервер:** настройте nginx на раздачу файлов из `dist/`. Серверная база данных, аккаунты и ключи API для этой версии не нужны. Для будущего защищённого бота потребуется отдельный backend/edge function.

## 7. Проверки и известные ограничения

Проверены `node --check` всех JS-модулей, `npm run build`, `npm test` (8 сценариев), существование и разбираемость GLB с 32 mesh-объектами, а также разбор GLB независимой библиотекой `trimesh`. HTTP-сервер успешно отдаёт HTML со статусом 200.

**Ограничение проверки:** в среде подготовки проекта автоматический браузер заблокировал открытие страниц (`ERR_BLOCKED_BY_ADMINISTRATOR`). Поэтому нельзя заявить о подтверждённых 60 FPS, pixel-perfect совпадении с референсом или успешных тестах в конкретных версиях Safari/Firefox/Chrome. Перед публикацией обязательно выполните браузерный чек-лист [docs/QA.md](docs/QA.md).

**Временные решения:** (1) трансформация представляет собой согласованное увеличение/затухание оригинального логотипа и «разворачивание» красного 3D-тела; топологический morph фирменных векторных контуров не выполнен; (2) 3D-модель тщательно приближена к референсу, но не является точной скульптурой/ригом авторского персонажа; (3) история, бот и фотографии мерча ожидаются от заказчика.
